Аннотация
Данная курсовая работа посвящена разработке графического MFC-приложения на языке программирования C++ для оценки устойчивости ПИН-кодов к угадыванию. Моя программа позволяет анализировать 4-х и 6-ти значные комбинации чисел по данным критериям: частоте встречаемости в утечках реальных баз данных, наличию повторяющихся цифр, последовательностей и т. д. По итогам анализа введённым пользователем кодам выдаётся оценка по десятибалльной шкале и выписывается вердикт в виде краткого текста с замечаниями. Все результаты анализа распределяются по трём категориям по надёжности: хорошие, средние и плохие комбинации. Также в программе предусмотрена возможность массовой обработки: ввод нескольких ПИН-кодов через запятую напрямую в программу или загрузка в поле из текстового файла. 

6. Разработка GUI приложения на языке C++ для анализа сложности PIN-кода
Сущность «PIN-код» (4-6 цифр) оценивается на основе частоты использования комбинаций в реальных утечках (данные из файла), наличия паттернов (1234, 0000, даты).
Приложение использует локальный файл со списком популярных/слабых PIN-кодов и статистику их встречаемости.
Пользователь вводит цифровой код; приложение возвращает оценку стойкости, список обнаруженных уязвимостей.
Приложение может предлагать альтернативные, более стойкие комбинации при обнаружении уязвимости.
Приложение должно поддерживать пакетную обработку — загрузку списка PIN-кодов из текстового файла (по одному в строке) или из многострочного поля ввода.
