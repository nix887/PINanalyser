Тема Курсовой: Разработка GUI приложения на языке C++ для анализа сложности PIN-кода — Оценка устойчивости 4-6-значного PIN к угадыванию на основе частоты использования комбинаций.
Автор: Илья И.

После выбора между 4х-значным кодом / 6ти-значным типом ПИН-код-анализа и ввода данных будет выдан вердикт и оценка. 
К примеру за 1111 пользователь получит сообщение:
Оценка: 1/10
Вердикт: Ваш ПИН-код слишком предсказуем и ненадежен, т. к. в нем есть повторяющиеся цифры и также он находится в топ 1% самых часто встречающихся комбинаций;
(только на английском т.к. Edit Control не поддерживает русский язык даже с Unicode (позже будет исправлено(возможно))
